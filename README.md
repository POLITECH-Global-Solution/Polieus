## Sobre o Projeto

O **Polieus** é uma plataforma CitizenTech desenvolvida para aproximar cidadãos e gestores públicos, promovendo uma gestão urbana mais participativa, acessível e transparente. A plataforma busca transformar ocorrências urbanas em informações organizadas, permitindo que a população registre problemas, acompanhe solicitações e compreenda melhor as decisões relacionadas à gestão pública.

## Objetivos

- Facilitar o registro e acompanhamento de ocorrências urbanas.
- Promover a acessibilidade e a participação cidadã.
- Organizar solicitações por categoria, localização e prioridade.
- Disponibilizar informações para apoiar decisões dos gestores públicos.
- Incentivar a transparência no acompanhamento das demandas.
- Contribuir para cidades mais inclusivas e sustentáveis.

## Escopo Inicial

O MVP do Polieus será concentrado em duas categorias:

**Acessibilidade:** calçadas danificadas, ausência de rampas, obstáculos e dificuldades de circulação.

**Pavimentação:** buracos, rachaduras e danos nas vias públicas.

## Funcionalidades Planejadas

### Área do Cidadão
- Cadastro e autenticação.
- Registro de ocorrências com descrição, localização e fotografia.
- Consulta e acompanhamento de solicitações.
- Visualização do histórico e status das ocorrências.
- Consulta de informações de transparência pública.

### Área Administrativa
- Painel geral de ocorrências.
- Gerenciamento e atualização das solicitações.
- Organização por categorias, regiões e prioridades.
- Relatórios e indicadores de gestão.
- Consulta de informações relacionadas ao orçamento público.

## Como Executar

### Pré-requisitos
- Git
- Node.js
- npm
- Visual Studio Code (recomendado)

### Clonar o repositório

    git clone https://github.com/POLITECH-Global-Solution/Polieus.git
    cd Polieus

### Instalar as dependências

    npm install

Alternativamente, utilize `npm ci` para instalar as versões registradas no arquivo de dependências.

### Iniciar o projeto

    npm run dev

### Validar o código

    npm run lint
    npm run build
